    ClipForge Studio • com.clipforge.studio • v1.0.0 — Android APK + Windows EXE

    🤖 Android — .apk

    Install directly on any Android phone. No Play Store account needed for direct install.

    WrapperCapacitor 6
    Outputapp-release.apk
    Min Android7.0 (API 24)
    SigningYour keystore — step 4
    1. Download the kit below, unzip it on your PC.
    2. Install Node 20+ + Android Studio.
    3. Run npm install then npx cap add android
    4. Create signing key: keytool -genkey -v -keystore clipforge.keystore -alias clipforge -keyalg RSA -keysize 2048 -validity 10000
    5. Run npx cap sync → open Android Studio → Build › Generate Signed APK.

    🪟 Windows — .exe

    Desktop installer for PC. Unsigned builds show a Windows “unknown publisher” prompt on first install — normal for personal use.

    WrapperTauri 2
    OutputClipForge-Setup.exe
    Windows10 / 11 • 64-bit
    Size target~8–15 MB installer
    1. Download the kit below, unzip it on your Windows PC.
    2. Install Node 20+, Rust (rustup.rs) + VS Build Tools.
    3. Run npm install then npm run tauri init if prompted.
    4. Copy tauri.conf.json into src-tauri/.
    5. Run npm run tauri build → installer is in src-tauri/target/release/bundle/.
